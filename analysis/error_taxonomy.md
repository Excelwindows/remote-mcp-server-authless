# Entry/ProVia door order-error taxonomy (from service-project notes, last yr)
Order-time-PREVENTABLE (what the watch-outs email should catch), ranked by observed recurrence:
1. CAPPING missing or wrong color — Kaczmarek "need to add door capping" -> ordered capping ProVia #13892053 + capping color from Richards Supply; storm-door capping color "cottage red #411". (capping/coil sometimes Richards Supply, not ProVia)
2. HARDWARE FINISH wrong — Kaczmarek strike plate "silver not gold like she wanted"; reordered gold hinges + striker plate.
3. WEATHERSTRIP / SWEEP / THRESHOLD -> DRAFT — Gruzlewski (weatherstrip + paint), Szcinski (threshold shim 1/4in + sweep seal, open winter->spring). Most recurring theme.
4. LOCK / STRIKER fit or defect — Waldridge "key does not work in lock, striker plate does not fit" -> reorder (new invoice #14294070); 2nd service c-clip/deadbolt.
5. TOUCH-UP PAINT needed — Gruzlewski, Kaczmarek.
NOT order errors (install/handling/product): scratches, caulk cosmetics, doorbell broken in install (Lam), screen/wheels/screws on Soft-Lite patio (Wollschlager).
